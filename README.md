# Data Structure

## 📌Overview

This project is a personal implementation of fundamental data structures and algorithms in Java.
The goal is not only to code them, but to deeply understand how each structure works internally, including pointer manipulation, recursion, balancing strategies, and time complexity trade-offs.

## Contents
   - Stack
   - LinkedList
   - Queue
   - Binary Search Tree
   - Balanced Binary Tree(AVL)
   - Sortings
   - Digital Tree
   - Heap
   - Graph
